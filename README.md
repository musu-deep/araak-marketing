# Araak Marketing Platform

منصة اراك لإدارة المناقصات وتسويق المشاريع هي منظومة رقمية تنفيذية متكاملة صُممت لخدمة مجموعة اراك في إدارة دورة حياة الفرص والمناقصات والمشاريع، من مرحلة الرصد والاستكشاف وحتى الإسناد والمتابعة والتقارير التنفيذية.

## الهدف

تحويل إدارة الفرص والمناقصات من عمل متفرق إلى منصة موحدة تساعد الإدارة العليا وفرق التسويق والمشاريع على:

* رصد الفرص والمناقصات.
* تقييم جاذبية الفرص واحتمالية الفوز.
* إدارة مراحل المناقصة.
* إسناد المهام لأعضاء الفريق.
* متابعة المسؤوليات والمساءلة.
* إدارة الوثائق والدروس المستفادة.
* إنتاج تقارير تنفيذية.
* تمكين صلاحيات مرنة حسب الأدوار.

## التقنيات المستخدمة

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase
* Supabase Auth
* PostgreSQL
* Row Level Security - RLS
* GitHub
* Vercel

## تفعيل البنية الخلفية

اتبع دليل [تفعيل Supabase](./SUPABASE_ACTIVATION.md) لربط المشروع، تطبيق migrations، نشر وظيفة دخول أعضاء المنصة، وإعداد متغيرات Vercel.

للتفعيل من PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\activate-supabase.ps1
```
